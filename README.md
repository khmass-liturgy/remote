# 슬라이드 리모컨

스마트폰으로 발표 슬라이드를 넘기고, 폰에서 현재·다음 슬라이드를 미리 보는 웹 프레젠테이션 리모컨입니다.
설치 없이 브라우저만으로 동작합니다.

## 사용법

1. **PC(프로젝터)** 에서 페이지를 열고 **화면으로 시작** → 발표할 PDF(또는 이미지 여러 장)를 엽니다.
   - 파워포인트는 `파일 → 내보내기 → PDF`로 저장해서 엽니다.
   - 파일은 어디에도 업로드되지 않고 그 PC 브라우저 안에서만 열립니다.
2. **스마트폰** 으로 화면의 QR코드를 찍거나, 페이지에서 6자리 코드를 입력합니다.
3. PC에서 **▶ 발표 시작** 을 누르면 전체화면으로 발표가 시작됩니다.

## 리모컨 기능

| 기능 | 설명 |
|---|---|
| ◀ ▶ | 이전 / 다음 슬라이드 (미리보기를 좌우로 쓸어도 됩니다) |
| 슬라이드 화면보기 | 현재·다음 슬라이드 미리보기, 전체 목록에서 원하는 장으로 바로 이동 |
| 🔴 포인터 | 미리보기를 손가락으로 짚으면 화면에 레이저 포인터 표시 |
| ⬛ 검은화면 | 화면을 잠시 가리기 |
| 타이머 | 누르면 시작/정지, 길게 누르면 초기화 |
| 메모 | 슬라이드별 발표 메모 (PC에 저장, 💾 Gist로 백업·다른 기기에서 불러오기) |

PC 화면 단축키: `→ ← PageDown PageUp Space` 넘기기, `Home/End`, `B` 검은 화면, `F` 전체화면, `Esc` 종료.
시중의 블루투스 프리젠터(클리커)도 그대로 쓸 수 있습니다.

## 연결 방식 (Wi-Fi / 블루투스)

두 기기는 WebRTC(PeerJS)로 직접 연결됩니다. 처음 서로를 찾을 때만 인터넷이 필요합니다.

- **Wi-Fi**: 같은 공유기든 서로 다른 망이든 둘 다 인터넷이 되면 연결됩니다.
- **모바일 데이터**: 폰은 LTE/5G, PC는 유선·Wi-Fi여도 됩니다.
- **블루투스**: 폰의 *블루투스 테더링*으로 PC를 연결하면 Wi-Fi 없는 곳에서도 동작합니다.
  (웹 브라우저는 블루투스 키보드(HID)처럼 동작할 수 없어서, 앱처럼 PC에 아무것도 열지 않고 블루투스만으로 파워포인트를 직접 조작하는 방식은 지원하지 않습니다.)

## 배포

정적 파일뿐이므로 GitHub Pages(`Settings → Pages → Deploy from a branch`)로 바로 서비스됩니다.
`vendor/`에는 pdf.js, PeerJS, qrcode-generator가 들어 있습니다.
